# Microsoft Azure Security Technologies (AZ-500) - Guided Labs

This repository contains my work from completing guided hands-on labs based on **Microsoft Azure Security Technologies (AZ-500)**.

The labs provided step-by-step instructions for configuring and securing different Azure services. I followed the provided exercises, performed the configurations in my Azure environment, and documented the steps and results with screenshots for reference.

## What's in here

* **Azure Firewall** - Guided lab covering the deployment and configuration of Azure Firewall to control network traffic within an Azure virtual network.

* **Azure Monitor, Microsoft Defender for Cloud, Just-In-Time VM Access & Microsoft Sentinel** - Guided exercises covering Azure monitoring, security recommendations, Just-In-Time VM access, and security event monitoring with Microsoft Sentinel.

* **Configuring and Securing ACR and AKS** - Guided lab covering security configurations for Azure Container Registry (ACR) and Azure Kubernetes Service (AKS), including access control and container image security.

* **Azure Key Vault & Always Encrypted** - Guided lab covering the use of Azure Key Vault for managing encryption keys and implementing Always Encrypted for protecting sensitive SQL data.

* **Network Security Groups and Application Security Groups** - Guided exercises covering the creation and configuration of NSGs and ASGs to control and organize network security rules.

* **Role-Based Access Control (RBAC)** - Guided lab covering the assignment and scoping of Azure RBAC roles to control access to Azure resources and apply least-privilege principles.

* **Securing Azure SQL Database** - Guided lab covering security configurations for Azure SQL Database, including firewall rules, auditing, and threat detection.

* **Service Endpoints and Securing Storage** - Guided exercises covering service endpoints and network-based access controls for securing Azure Storage resources.
